=head1 NAME

entropy_src - Cryptographically Secure Random Number Generation

=head1 SYNOPSIS

#include "entropy_src.h"

int open_entropy_source(void);

int entropy_src(unsigned char *output, size_t ilen, size_t *olen);

=head1 DESCRIPTION

The C<entropy_src> function and its helper C<open_entropy_source> are designed to generate cryptographically secure random bytes using platform-specific sources. They support Windows, macOS, and Unix-like systems by abstracting their respective APIs and filesystems for entropy generation.

=head1 FUNCTIONS

=head2 open_entropy_source

Attempts to open the most suitable entropy source available on the system, trying /dev/hwrng first, then /dev/urandom, and /dev/random as a last resort.

Returns the file descriptor of the opened entropy source, or -1 if all attempts fail.

=head2 entropy_src

Generates a specified number of cryptographically secure random bytes and writes them into the provided output buffer. The actual number of generated bytes is returned through the olen pointer.

On Windows, this function uses BCryptGenRandom. On macOS, it uses SecRandomCopyBytes. On other Unix-like systems, it tries to read from /dev/hwrng, /dev/urandom, or /dev/random, in that order of preference.

=head1 PARAMETERS

=over 4

=item * C<output>

Pointer to the buffer where the random bytes will be stored.

=item * C<ilen>

Number of bytes to generate.

=item * C<olen>

Pointer to a size_t variable where the function will store the actual number of generated bytes.

=back

=head1 RETURN VALUES

=over 4

=item * 0

Success.

=item * -1

Invalid arguments.

=item * -2

Error generating random bytes (Windows only).

=item * -3

Error opening the entropy source.

=item * -4

Error reading from the entropy source.

=back

=head1 EXAMPLES

To generate 128 bytes of random data:

    unsigned char buffer[128];
    size_t bytes_generated;
    int result = entropy_src(buffer, sizeof(buffer), &bytes_generated);
    
    if (result == 0) {
        // Use buffer
    }
