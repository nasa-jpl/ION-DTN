=head1 NAME

bpcrash_hard - Bundle Protocol transaction crash test utility (with SDR modification)

=head1 SYNOPSIS

B<bpcrash_hard>

=head1 DESCRIPTION

B<bpcrash_hard> is an enhanced test utility that forces a Bundle Protocol
transaction to be cancelled after the SDR has been modified.  This ensures
that transaction reversal logic is properly exercised in ION 4.1.3 and later
versions.

Unlike the original B<bpcrash> utility, B<bpcrash_hard> explicitly modifies
the SDR by allocating space and writing data before cancelling the transaction.
This guarantees that the "sdr->modified" flag is set, which is required to
trigger transaction reversal in ION 4.1.3+.

The utility performs the following steps:

=over 4

=item 1.

Attaches to Bundle Protocol

=item 2.

Begins an SDR transaction

=item 3.

Allocates 10,000 bytes in the SDR

=item 4.

Writes test data to the allocated space (marks transaction as modified)

=item 5.

Cancels the transaction, triggering reversal

=item 6.

Waits briefly for ionrestart to execute (if configured)

=back

When the transaction is cancelled with modifications present, ION will:

=over 4

=item *

Log "Attempting transaction reversal..." message

=item *

Execute the reversal process to roll back SDR changes

=item *

Execute the restartCmd (typically ionrestart) if configured

=item *

Halt the SDR to allow restart utility to reinitialize volatile state

=back

=head1 EXIT STATUS

=over 4

=item C<0>

Transaction successfully created and cancelled.

=item C<1>

B<bpcrash_hard> was unable to attach to Bundle Protocol or allocate SDR space.

=back

=head1 USAGE

B<bpcrash_hard> is typically used in automated tests of ION's transaction
reversibility mechanisms.  It is run while ION is operational to simulate
a crash condition that requires transaction reversal.

Example test sequence:

    # Start ION
    ionstart

    # Run bpcrash_hard to trigger reversal
    bpcrash_hard

    # Verify ionrestart executed
    # Check for "Attempting transaction reversal" in ion.log

    # Restart daemons manually if needed
    ionadmin restart.ionrc
    bpadmin restart.bprc

    # Verify system recovered
    bpdriver 10 ipn:1.1 ipn:2.1 -100

=head1 FILES

No configuration files are required.

=head1 ENVIRONMENT

No environment variables apply.

=head1 DIAGNOSTICS

The following diagnostics may be issued to the B<ion.log> log file:

=over 4

=item bpcrash_hard: Can't attach to BP.

Bundle Protocol functionality was not initialized. Run ionadmin first.

=item bpcrash_hard: Can't allocate SDR space.

Insufficient SDR heap space available. This is unexpected and indicates
a severely constrained or corrupted SDR.

=item bpcrash_hard: Forcing transaction cancellation with modifications.

Normal output indicating the transaction is being cancelled after SDR
modifications were made.

=item bpcrash_hard: Transaction aborted.

Normal output confirming transaction cancellation.

=item Attempting transaction reversal...

Expected message from SDR library indicating reversal is being performed.

=back
