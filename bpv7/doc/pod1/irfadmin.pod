=head1 NAME

irfadmin - BP inter-regional forwarding (IRF) adminstration utility

=head1 SYNOPSIS

B<irfadmin> [ I<commands_filename> ]

=head1 DESCRIPTION

B<irfadmin> assists in the management of the local ION node's database
of inter-regional forwarding information, specifically the regions in which
the local node and other known nodes reside.

B<irfadmin> operates in response to IRF configuration commands found in
the file I<commands_filename>, if provided; if not, B<irfadmin> prints
a simple prompt (:) so that the user may type commands directly into
standard input.

The format of commands for I<commands_filename> can be queried from B<irfadmin>
with the 'h' or '?' commands at the prompt.  The commands are documented in
irfrc(5).

=head1 EXIT STATUS

=over 4

=item "0"

Successful completion of IRF administration.

=item "-1"

Unsuccessful completion of IRF administration, due to inability to
attach to the Bundle Protocol system .

=back

=head1 EXAMPLES

=over 4

=item irfadmin

Enter interactive IRF administration command entry mode.

=item irfadmin host1.irfrc

Execute all configuration commands in I<host1.irfrc>, then terminate
immediately.

=back

=head1 FILES

See irfrc(5) for details of the IRF administration commands.

=head1 ENVIRONMENT

No environment variables apply.

=head1 DIAGNOSTICS

B<Note>: all ION administration utilities expect source file input to be
lines of ASCII text that are NL-delimited.  If you edit the irfrc file on
a Windows machine, be sure to B<use dos2unix to convert it to Unix text format>
before presenting it to B<irfadmin>.  Otherwise B<irfadmin> will detect syntax
errors and will not function satisfactorily.

The following diagnostics may be issued to the logfile ion.log:

=over 4

=item irfadmin can't attach to BP.

Bundle Protocol has not been initialized on this computer.  You need to run
bpadmin(1) first.

=item Can't open command file...

The I<commands_filename> specified in the command line doesn't exist.

=back

Various errors that don't cause B<irfadmin> to fail but are noted in the
B<ion.log> log file may be caused by improperly formatted commands
given at the prompt or in the I<commands_filename> file.
Please see irfrc(5) for details.
